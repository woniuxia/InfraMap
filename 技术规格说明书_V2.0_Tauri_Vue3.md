# InfraMap Desktop 技术规格说明书

**技术栈**：Tauri 2.0 + Vue 3 + TypeScript + SQLite + AntV G6 5.x

**版本**：V2.1

---

## 1 项目概述

离线桌面客户端，维护服务器、应用、中间件基础信息及调用关系，拓扑图展示服务依赖。目标用户：运维、开发、架构师。

核心特性：完全离线、数据本地存储、网状拓扑图、自动备份与恢复。

- **存储位置**：OS标准应用数据目录

- **备份**：支持自动/手动，详见 4.5

### 2.3 数据库迁移

`schema_version` 表记录当前版本：

```sql
CREATE TABLE IF NOT EXISTS schema_version (
    version INTEGER NOT NULL,
    applied_at TEXT NOT NULL
);
```

启动时对比代码目标版本，低于则按序执行迁移函数，每次迁移在事务中执行。失败回滚并阻止启动。迁移脚本以数组组织，新增只需追加。

## 4 功能模块

### 4.1 仪表盘

- **资源统计卡片**：各类资源总数 + 异常状态数（stopped/maintenance）
- **最近变更**：`audit_logs` 按 `created_at` 倒序取20条，展示操作类型/资源名/时间
- **环境分布**：按 prod/dev/test 统计资源数，饼图或柱状图

### 4.2 资源管理

四类资源（服务器、应用、中间件、Nginx）的 CRUD，统一行为：
- 列表支持搜索（名称/IP）、筛选（类型/环境/状态）、分页
- 新增编辑使用右侧抽屉表单
- 删除均为软删除
- 服务器详情展示已部署服务列表；中间件详情展示使用方应用列表

**Nginx 特殊逻辑**：通过 `deployments` 关联服务器，通过 `dependencies` 建立调用链（前端应用 -> Nginx -> 后端应用），实现负载均衡链路在拓扑图中完整呈现。

### 4.3 关系管理

- **部署关系**：应用/中间件/Nginx <-> 服务器，支持一对多
- **调用关系**：服务间依赖，区分 http_call/tcp/mq_produce/mq_consume；Nginx 可作为中间节点；在应用详情中维护下游依赖

### 4.4 拓扑可视化

**节点样式**

| 类型 | 形状 | 状态色 |
|------|------|--------|
| 服务器 | 矩形容器（Combo） | running=正常 / stopped=灰 / maintenance=橙 |
| 应用 | 圆形 | 同上 |
| 数据库 | 圆柱形 | 同上 |
| 消息队列 | 消息图标 | 同上 |
| Nginx | 盾牌图标 | 同上 |

**连线样式**

| 关系类型 | 样式 |
|----------|------|
| HTTP调用 | 实线箭头 |
| 数据库读写 | 带标签实线 |
| 消息队列 | 虚线 |
| 部署关系 | 虚线框包裹 |

**搜索与筛选**

- 搜索框：匹配名称/IP/类型，匹配节点高亮，其余 dimmed，回车跳转下一个匹配，显示计数（如 "3/15"）
- 类型筛选：按钮组（应用/数据库/消息队列/服务器/Nginx），支持多选
- 环境筛选：下拉框（全部/prod/dev/test），非匹配节点隐藏或置灰

**路径追踪**

操作：Ctrl + 依次点击两节点。BFS 计算所有可达路径，高亮路径元素，右侧面板列出跳转链路。点击空白退出。达到上限时提示"仅显示前 N 条路径"。

**影响分析**

操作：右键节点 -> "影响分析"。反向遍历 `dependencies`，标记所有上游服务，警告色按层级深度渐变。右侧面板展示影响统计（受影响数/层级深度）和依赖树。

**其他**

- 图导出：PNG / SVG，保留缩放和高亮状态
- 交互：滚轮缩放、拖拽画布、悬停高亮上下游、点击弹详情面板、布局切换（力导向/层次）

### 4.5 备份与恢复

**自动备份**

- 启动时检查上次备份时间，超过间隔（默认24h）则执行
- 运行期间后台线程周期检查
- 使用 SQLite Online Backup API 备份（非文件复制，WAL 安全）
- 文件名：`inframap_backup_YYYYMMDD_HHmmss.db`
- 保留策略：默认最近10份，超出删最旧

**手动操作**

- 一键备份：触发一次数据库备份
- 导出 JSON：全量实体 + 关系，结构化 JSON
- 导出 SQL：建表语句 + INSERT
- 存档：选多个备份压缩为 .zip

**恢复**

- 从 .db 恢复：预览摘要（各表记录数/时间），恢复前自动安全备份当前库
- 从 JSON 恢复：支持覆盖或合并

**设置项**：自动备份开关（默认开）、间隔（默认24h）、最大保留数（默认10）

### 4.6 系统管理

- 数据导出：JSON / SQL
- 数据导入：JSON / CSV（服务器信息）
- 系统设置：备份策略配置

## 6 关键技术实现

### 6.1 数据库连接池

```rust
use r2d2::Pool;
use r2d2_sqlite::SqliteConnectionManager;
use tauri::Manager;

pub type DbPool = Pool<SqliteConnectionManager>;

pub fn init_db_pool(db_path: &str) -> Result<DbPool, Box<dyn std::error::Error>> {
    let manager = SqliteConnectionManager::file(db_path)
        .with_init(|conn| {
            conn.execute_batch(
                "PRAGMA journal_mode=WAL;
                 PRAGMA foreign_keys=ON;
                 PRAGMA busy_timeout=5000;"
            )
        });
    let pool = Pool::builder()
        .max_size(8)
        .build(manager)?;
    Ok(pool)
}

fn main() {
    tauri::Builder::default()
        .setup(|app| {
            let pool = init_db_pool(&db_path)?;
            app.manage(pool);
            Ok(())
        })
        .run(tauri::generate_context!())
        .expect("error running app");
}
```

### 6.3 路径追踪算法

BFS 搜索两节点间所有路径，`max_depth` 防环路，`max_results` 防内存爆炸。

```rust
pub fn find_all_paths(
    graph: &HashMap<String, Vec<String>>,
    source: &str,
    target: &str,
    max_depth: usize,    // 默认10
    max_results: usize,  // 默认20
) -> Vec<Vec<String>> {
    let mut results = Vec::new();
    let mut queue: VecDeque<Vec<String>> = VecDeque::new();
    queue.push_back(vec![source.to_string()]);

    while let Some(path) = queue.pop_front() {
        if results.len() >= max_results { break; }
        if path.len() > max_depth { continue; }
        let current = path.last().unwrap();
        if current == target {
            results.push(path);
            continue;
        }
        if let Some(neighbors) = graph.get(current) {
            for neighbor in neighbors {
                if !path.contains(neighbor) {
                    let mut new_path = path.clone();
                    new_path.push(neighbor.clone());
                    queue.push_back(new_path);
                }
            }
        }
    }
    results
}
```

### 6.4 影响分析算法

反向 BFS 遍历依赖图，收集上游节点及层级深度。

```rust
pub struct ImpactResult {
    pub affected_nodes: Vec<AffectedNode>,
    pub total_count: usize,
    pub max_depth: usize,
}

pub struct AffectedNode {
    pub id: String,
    pub name: String,
    pub node_type: String,
    pub depth: usize,
}

pub fn analyze_upstream_impact(
    reverse_graph: &HashMap<String, Vec<String>>,
    node_id: &str,
) -> ImpactResult {
    let mut affected = Vec::new();
    let mut visited = HashSet::new();
    let mut queue: VecDeque<(String, usize)> = VecDeque::new();

    visited.insert(node_id.to_string());
    queue.push_back((node_id.to_string(), 0));

    while let Some((current, depth)) = queue.pop_front() {
        if let Some(upstreams) = reverse_graph.get(&current) {
            for upstream in upstreams {
                if visited.insert(upstream.clone()) {
                    affected.push(AffectedNode {
                        id: upstream.clone(),
                        depth: depth + 1,
                        ..Default::default()
                    });
                    queue.push_back((upstream.clone(), depth + 1));
                }
            }
        }
    }

    let max_depth = affected.iter().map(|n| n.depth).max().unwrap_or(0);
    ImpactResult {
        total_count: affected.len(),
        max_depth,
        affected_nodes: affected,
    }
}
```

### 6.5 自动备份实现

```rust
pub fn check_and_auto_backup(pool: &DbPool, settings: &BackupSettings) -> Result<(), String> {
    if !settings.auto_backup_enabled { return Ok(()); }

    let backup_dir = get_backup_dir()?;
    let last_backup_time = get_latest_backup_time(&backup_dir)?;

    if should_backup(last_backup_time, settings.interval_hours) {
        create_db_backup(pool, &backup_dir)?;
        cleanup_old_backups(&backup_dir, settings.max_backups)?;
    }
    Ok(())
}

/// SQLite Online Backup API（WAL安全）
fn create_db_backup(pool: &DbPool, backup_dir: &Path) -> Result<String, String> {
    use rusqlite::backup::Backup;

    let timestamp = chrono::Local::now().format("%Y%m%d_%H%M%S");
    let backup_name = format!("inframap_backup_{}.db", timestamp);
    let backup_path = backup_dir.join(&backup_name);

    let conn = pool.get().map_err(|e| e.to_string())?;
    let mut dst = rusqlite::Connection::open(&backup_path).map_err(|e| e.to_string())?;
    let backup = Backup::new(&conn, &mut dst).map_err(|e| e.to_string())?;
    backup.run_to_completion(100, std::time::Duration::from_millis(250), None)
        .map_err(|e| e.to_string())?;

    Ok(backup_name)
}

/// 后台定时备份线程
pub fn start_backup_timer(pool: DbPool, settings: BackupSettings) {
    std::thread::spawn(move || {
        loop {
            std::thread::sleep(std::time::Duration::from_secs(
                settings.interval_hours as u64 * 3600
            ));
            if settings.auto_backup_enabled {
                let backup_dir = match get_backup_dir() {
                    Ok(dir) => dir,
                    Err(_) => continue,
                };
                let _ = create_db_backup(&pool, &backup_dir);
                let _ = cleanup_old_backups(&backup_dir, settings.max_backups);
            }
        }
    });
}

fn cleanup_old_backups(backup_dir: &Path, max_count: usize) -> Result<(), String> {
    let mut backups: Vec<_> = std::fs::read_dir(backup_dir)
        .map_err(|e| e.to_string())?
        .filter_map(|e| e.ok())
        .filter(|e| e.path().extension().map_or(false, |ext| ext == "db"))
        .collect();
    backups.sort_by_key(|e| e.metadata().and_then(|m| m.modified()).unwrap_or(std::time::SystemTime::UNIX_EPOCH));

    while backups.len() > max_count {
        if let Some(oldest) = backups.first() {
            std::fs::remove_file(oldest.path()).map_err(|e| e.to_string())?;
            backups.remove(0);
        }
    }
    Ok(())
}
```
